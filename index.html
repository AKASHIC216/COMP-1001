Module 1

Computer Fundamentals

Computers are part of nearly every aspect of modern life. We use them to communicate, complete schoolwork, conduct business, entertain ourselves, and access information.

Although many people use computers every day, they may not know what is actually happening inside the computer. In this module, you will learn the basic components of a computer and how hardware and software work together.

You do not need any previous technical experience for this module. The goal is not to memorize complicated terminology. Instead, you will develop a practical understanding of how computers work.

Learning Objectives

By the end of this module, you should be able to:

  • Define a computer and describe its basic functions.
  • Distinguish between hardware and software.
  • Identify the major internal components of a computer and explain their purposes.
  • Explain the basic roles of the CPU, RAM, storage, motherboard, and GPU.
  • Distinguish between input, processing, output, and storage.
  • Compare common types of computers and computing devices.
  • Explain the difference between system software and application software.
  • Use basic computer specifications to compare computers.

Lesson 1.1 — What Is a Computer?

At its most basic level, a computer is an electronic device that accepts data, processes that data according to instructions, stores information, and produces output.

Example: Writing a Paper

Imagine that you are typing a paper using a word-processing program.

  • Input: You press keys on the keyboard.
  • Processing: The computer processes the keystrokes and determines which characters should appear.
  • Output: The letters appear on your monitor.
  • Storage: When you save the document, the file is stored on the computer's storage device.
Important:

A computer does not have to be a desktop or laptop. Smartphones, tablets, game consoles, smart televisions, automobiles, servers, and many other devices contain computers. In fact it is accurate to say that the vast majority of computers in existence are embedded devices. Some examples of embedded device would be your phone, smart watch, Roku streaming device, smart refrigiatros and other smart devices you use each day.

Lesson 1.2 — Hardware and Software

Every computer system depends on both hardware and software. Understanding the difference between the two is one of the foundations of computer literacy.

Hardware

Hardware refers to the physical components of a computer. These are the parts that you can physically touch.

Examples include:

  • Keyboard
  • Mouse
  • Monitor
  • CPU
  • RAM
  • SSD
  • Motherboard
  • Graphics card

Software

Software consists of programs and instructions that tell computer hardware what to do.

Examples include:

  • Microsoft Windows
  • Microsoft Word
  • Web browsers
  • Games
  • Media players

  2. Google Chrome
  3. RAM

RAM is a physical component installed inside a computer. The other choices are software.

Lesson 1.3 — Inside the Computer

A computer contains several major components that work together. You do not need to understand the electrical engineering behind these components, but you should understand what each component contributes to the computer.

CPU

The Central Processing Unit, or CPU, executes instructions and performs calculations needed to run programs.

RAM

Random Access Memory provides temporary working space for programs and information currently being used by the computer. This type of memeory is refered to as volitile memory since once you shutoff the computer whatever was in the memory disappears.

Storage

Storage devices such as solid-state drives (SSDs) and hard disk drives (HDDs) store programs and files even after the computer is turned off.

Motherboard

The motherboard is the primary circuit board that connects the major components of the computer and allows them to communicate.

GPU

The Graphics Processing Unit processes graphics and can perform large numbers of calculations in parallel.

GPUs are commonly used for graphics, gaming, video production, scientific computing, and artificial intelligence.

Power & Cooling

The power supply provides electrical power to computer components, while fans and heatsinks help remove the heat those components produce.

RAM vs. Storage

RAM and storage are commonly confused, but they serve very different purposes.

Think of a Desk and Filing Cabinet

Imagine that RAM is your desk. The larger your desk, the more books, papers, and other materials you can have open while you work.

Storage is your filing cabinet. It holds your documents and information when you are not actively using them.

Therefore, a computer with 16 GB of RAM and a 1 TB SSD has 16 GB of temporary working memory and approximately 1 TB of long-term storage.

Lesson 1.4 — Input and Output Devices

Computers communicate with users through input and output devices.

Input Devices

Input devices allow information to be sent to the computer.

  • Keyboard
  • Mouse
  • Microphone
  • Scanner
  • Webcam

Output Devices

Output devices allow the computer to present information to the user.

  • Monitor
  • Speakers
  • Printer
  • Projector

Think About It

Is a touchscreen an input device or an output device?

Show Answer

It is both.

The screen provides visual output, while touching the screen provides input to the computer.

Lesson 1.5 — Types of Computers

Computers come in many different forms. The appropriate type of computer depends on what it needs to accomplish.

  • Desktop Computer — designed primarily for use at a desk.
  • Laptop — portable computer with an integrated display, keyboard, and battery.
  • Tablet — portable computer designed primarily around a touchscreen interface.
  • Smartphone — mobile computing device combining communication and computing capabilities.
  • Workstation — high-performance computer often used for specialized professional workloads.
  • Server — computer designed to provide services or resources to other computers.
  • Embedded Computer — computer built into another device to perform a particular function.

What About Virtual Computers?

Computers do not always have to correspond to one physical machine. Through a technology called virtualization, one physical computer can run multiple virtual computers called virtual machines.

We will explore concepts such as this in greater detail later in the course.
